# Nexus-inspired JevCode mockups

These concept images apply the visual language documented in the read-only
`Octran-Nexus` reference repository to JevCode's existing product screens.
They are design proposals, not screenshots of running JevCode. Task details,
provider connection states, model counts, repository status, and usage figures
are illustrative.

| Image | Screen | Design focus |
| --- | --- | --- |
| [01-active-task.png](01-active-task.png) | Active coding task | Three-pane work area, tool activity, approval, change review, composer |
| [02-project-overview.png](02-project-overview.png) | Project overview | Repository state, recent tasks, aligned file tree, project context |
| [03-accounts-providers.png](03-accounts-providers.png) | Accounts and providers | Multi-provider connection states and credential entry |
| [04-local-usage.png](04-local-usage.png) | Local Agent Usage | Request metrics, token trend, provider and project breakdowns |

The reference's defining cues are a matte near-black canvas (`#0b0b0c`),
graphite surfaces (`#131315`), a slightly warm sidebar, thin technical
dividers, compact Inter text, and small uppercase monospace labels. Orange
(`#ff5e1a`) marks the primary action or selected location, while indigo is
reserved for approval and governance states. The mockups keep JevCode's
project/sidebar, conversation, inspector, and settings architecture.

Reference material was read from `Octran-Nexus/DESIGN.md`,
`Octran-Nexus/docs/design-system.md`,
`Octran-Nexus/docs/cowork-three-panel-structure.md`, and
`Octran-Nexus/packages/ui/src/styles/globals.css`. The reference repository
was not modified.
